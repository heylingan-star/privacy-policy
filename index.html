Privacy Policy

SealCaptain Ads API · Effective Date: October 10, 2026

1. Introduction

This Privacy Policy describes how SealCaptain Ads API (the “Application”), operated by 福州小番茄商贸有限公司, collects, uses, stores, and protects information obtained through the Amazon Advertising API and Login with Amazon (LWA).

The Application is intended for internal advertising management and analytics purposes.

2. Information We Access

With authorized account access, the Application may process:

  • Amazon Advertising account and profile information.
  • Advertising campaigns, ad groups, keywords, targeting settings, and bids.
  • Advertising performance data, including impressions, clicks, costs, and attributed sales.
  • OAuth authentication tokens required for authorized API access.

The Application does not intentionally request Amazon customer passwords or individual shoppers’ personal information.

3. How We Use Information

We use authorized advertising data to:

  • Monitor advertising campaign performance.
  • Generate advertising reports and analytics.
  • Identify campaign optimization opportunities.
  • Manage advertising campaigns, budgets, bids, and targeting settings when authorized.

4. Data Storage and Security

We implement reasonable technical and organizational safeguards designed to protect advertising data and authentication credentials against unauthorized access, disclosure, or misuse.

Access is restricted to authorized personnel and systems. Authentication credentials are handled separately from public application content.

5. Data Sharing

The Application is intended for internal business use and does not sell Amazon Advertising data.

Advertising data may be processed by authorized technology service providers when necessary to operate the Application, subject to applicable agreements and security requirements.

6. Data Retention and Deletion

We retain advertising data and authentication information only as long as reasonably necessary for legitimate business purposes, subject to applicable legal, contractual, and Amazon API requirements.

Authorized users may request deletion of applicable stored information or revocation of application access by contacting us.

7. Third-Party Services

The Application uses Amazon Advertising API and Login with Amazon services. Data processing is also subject to applicable Amazon terms and policies.

8. Changes to This Policy

We may update this Privacy Policy to reflect changes in our Application, data practices, or legal obligations. Updates will be published on this page.
